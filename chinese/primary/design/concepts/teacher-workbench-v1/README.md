## 视觉语言

- 材质：导航为**半哑光珐琅书脊**；内容区为**冷调厚卡纸**。边缘厚度、遮挡与冷色阴影表示信息层级，纹理仅作细微辅助。
- 屏幕候选四色：深墨蓝 `#1C2745`、冷纸白 `#F2F5FA`、电光蓝 `#3157D4`、亮洋红 `#AF1D88`。同色透明度/明度可形成阴影和纸面层次；品牌色之外不再引入暖色。A4 输出使用黑白灰。
- 入口可鲜艳，主内容以深墨蓝和冷纸白为主；UI 程序实现时应量测色值、文字对比度、高彩面积，不能仅凭概念图断言精确符合四色。
- 田字格、拼音格线、作文批注用作小学语文学科线索；除练习纸外不让装饰占据工作区。
