## 四色

| 用途 | 色值 | 使用规则 |
|---|---|---|
| 墨蓝 | `#1C2745` | 导航书脊、正文、深色内凹台面 |
| 冷纸白 | `#F2F5FA` | 页面与纸张底色、深底上的文字 |
| 电光蓝 | `#3157D4` | 当前项、主要行动、焦点 |
| 亮洋红 | `#AF1D88` | 次级高亮、批注与待跟进提示 |

屏幕禁用橙、黄、绿、暖白和额外色相。边线、投影、纸纹、悬停使用以上四色的透明度或同色明度派生。打印纸黑白灰是输出介质。状态必须同时有文字和形状，不能单靠蓝/洋红区分。正文对比度 ≥4.5:1，非文字控件 ≥3:1。

## 材质与层级

1. 左导航是半哑光珐琅书脊：墨蓝底、压入式分隔、选中项用电光蓝实心厚片；徽标以语文书页线条表达。
2. 页面是冷调厚卡纸：细微纤维感只能通过 CSS 实现，纹理不能覆盖正文；内容容器有 1–3px 的可见边厚与冷色阴影。
3. 页面底层、内容卡、浮起操作最多三级。阴影只表达可操作/分组关系，不叠无信息的装饰卡。
4. 正常业务屏幕以墨蓝、纸白占大面积，高彩集中在主行动、选中导航、批注锚点。目标高彩面积不超过约 20%。

## 页面与交互

- 一级导航：今日、教学、批改、资料与打印、班级、设置。听写是教学中的任务，错词与复查归批改。
- 顶部始终显示当前班级和册别；切班后所有班级记录同步切换。首页没有事实记录时显示空状态，不出现示例任务或非零统计。
- 业务卡先呈现状态与下一步行动；数字可回到来源任务。名单和表格支持键盘，焦点清晰，200% 缩放仍能操作。
- 田字格、拼音线、作文批注仅作学科线索；教师业务文字优先。系统中文字体和内联 SVG，零外链字体/图标。
- A4 学生纸只包含题目提示和作答空间；答案独立打印。网页导航与装饰绝不进入纸张。

## 实施和验收

界面依据真实数据渲染，概念图中自动生成的日期、课文内容、词频和拼音不进入生产数据。验收需截取正常、空、长文本、50 人名册四类状态；量测实际 CSS 色值、对比度、200% 缩放和 A4 打印。G1 是方向批准，不能替代 G2–G5。
