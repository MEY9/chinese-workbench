# ZCode 改动后的 UI/UX 审查

> 最新决策：用户再次指定此前冷纸书脊概念图，要求恢复有质感的 UI。下表 P0 视觉修正重新适用；教材与 PDF UX 修正继续保留。当前视觉依据 `../UI-设计语言-v1.md`。

日期：2026-10-23。范围：`app/index.html#resources`、教材阅读子页，以及共用视觉系统。审查依据为已批准的 `PRD-教师工作台-v1-待审.md`、`UI-设计语言-v1.md` 和源码。自动浏览器工具拒绝本地 `file://` 页面，因此以下已修复项经代码和测试验证，真实页面截图、键盘与打印外观仍待 G4 人工验收。

## 核心发现与处理

| 优先级 | 问题 | 对教师的影响 | 处理 |
|---|---|---|---|
| P0 | v2 暖白、橙黄绿、六种导航色与已批准的冷调四色规范冲突 | 工作台失去既定的克制和材质层次，也无法按 G1 色彩门禁验收 | 屏幕色值收敛为墨蓝、冷纸白、电光蓝、亮洋红；恢复深色书脊、厚纸卡边和冷色阴影，打印介质仍为黑白灰 |
| P0 | 资料页默认打开三上待核样例，内置 PDF 在第二页签 | 教师首先看到不适用于多数班级的旧内容，难以找到教材 | 默认进入教材目录；当前班级绑定教材置于目录上方，提供直接阅读入口 |
| P1 | 已绑定教材仍显示“绑定到本班” | 状态和动作冲突，易误触或误判 | 当前书显示“本班已绑定”，隐藏重复绑定按钮，排在目录首位 |
| P1 | 临时选择的 PDF 可被标为统编版教材 | 造成教材来源与永久保存状态误解 | 阅读器显示真实文件名与“本次会话临时预览”，关闭需重新选择 |
| P1 | 12 册 PDF 均挤在单列，元数据登记表抢占半屏 | 教材比较和定位效率低 | 目录改宽布局，增加年级、册别、出版社筛选；登记表收起为次级操作 |
| P1 | 设置页仍写“教材待导入”，而本机已入包 12 册 | 状态过期，降低可信度 | 更新设置文案；目录明确说明当前只有实际入包出版社，课次与内容仍待核 |
| P2 | PDF 阅读子页缺少原生阅读器兜底和浏览器返回路径 | 嵌入阅读器不可用时无退路 | 增加“在新窗口打开”；PDF 写入 hash，返回后释放临时 blob |
| P2 | 打印资料页让未校对词库占据首屏 | 常用空白听写纸和备课摘要不易找到 | 常用纸张前置；样例词库仅在未绑定的三年级上册班级显示 |
| P2 | 筛选后焦点丢失、确认弹窗缺少 Esc 和焦点恢复 | 键盘操作被迫从页面起点重来 | 筛选与页签刷新后恢复焦点；确认、信息与打印预览层支持 Esc，弹窗关闭后还原焦点 |

## 保留的功能

保留 IndexedDB、班级隔离、备份恢复、12 册 PDF 文件及哈希校验、教师自行登记其他出版社目录、课次页码待核标记。文件存在与 SHA-256 通过不等于版权页、出版社、课文、拼音和页码已经校对。目前 `contentVerified=false`，不能宣称覆盖“各个出版社”。
