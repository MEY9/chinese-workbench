## 1. 项目是什么

**「小语工作台」**——给中国小学语文老师用的**完全本地化**个人教学工作台。入口是单个 HTML 文件,双击打开即用,不需要安装、不需要联网、数据只存本机。

它同时是一个**多工作台平台**的第一个实例。后续会开发数学、英语等其他科目/学段的工作台,所以平台层的可复用资产和流程已经先行建好,必须遵守(见 §3、§4)。

用户画像:小学语文老师,不懂技术,常兼班主任。核心痛点(小红书调研结论):作文批改耗时、听写默写每日刚需、生字词打印需求大、备课找资料累、语文老师工作繁杂。

## 3. 铁律:开发流程与审批门

`workbench/PROCESS.md` 是强制流程:**小红书调研需求 → 【用户审批功能范围】 → OpenAI兼容接口生图UI → 【用户审批视觉稿】 → 开发 → 交付登记**。

- 每完成一步要更新 `workbench/INDEX.md` 的状态行(状态机:调研中→PRD已批→视觉待审→开发中→已交付)。

## 4. 硬约束(违反=返工)

1. **单文件 HTML**:交付物始终是单个 `index.html`,零框架、零 CDN、零构建依赖,必须支持 `file://` 双击直接打开。
2. **完全本地化**:数据只存本机;除用户在设置页显式配置的 AI 服务外,禁止任何网络请求。密钥绝不写进代码/Git/产物。
3. **改模板不改进产物**:源码是 `index.template.html`,构建方式:
   ```bash
   cd E:\codex\jiaosdhi\workbench\chinese\primary\app
   python -c "tpl=open('index.template.html',encoding='utf-8').read(); bank=open('bank.json',encoding='utf-8').read(); open('index.html','w',encoding='utf-8').write(tpl.replace('__BANK__',bank))"
   ```
   模板里 `__BANK__` 占位符会被词库 JSON 替换。
4. **JS 语法自检**(每次改完必做;node 在 PATH 里):
   ```bash
   python -c "import re; src=open('index.template.html',encoding='utf-8').read(); open('_check.js','w',encoding='utf-8').write('\n;\n'.join(re.findall(r'<script>(.*?)</script>', src.replace('__BANK__','{}'), re.S)))"
   node --check _check.js && rm _check.js
   ```
5. **系统字体、内联 SVG 图标**,不引入 webfont/图标库/图片文件。
6. 中文一律 UTF-8;中文参数走文件不进命令行(防 Git Bash 编码损坏)。

## 5. 技术架构(现状 P0)

- **路由**:hash 路由,`VIEWS = ['home','chars','dict','wrong','bank','set']`,`go(v)` 切视图;侧栏导航 5 项,错词本从首页卡片/听写页进入。
- **存储**:localStorage(注意:PRD 写的是 IndexedDB,实际实现用了 localStorage——数据量小、file:// 下最稳,已在交付时向用户说明,属已确认偏差)。键名约定:`wb_settings`(AI配置)、`wb_classes`/`wb_cls`(班级)、`wb_lesson`(当前课文no)、`wb_bank`(词库用户修改 override)、`wb_wrong`(错词本 [{w,p,ts}])、`wb_dpick_<课号>`(听写勾选)、`wb_voice`(TTS嗓音)。
- **词库**:内置 `window.BANK`(部编版三上 16 课/185字/132词)。读取顺序:`S.override[课号]` 覆盖内置。**拼音由 pypinyin 0.55.0 生成**(多音字特殊读音在 `make_bank.py` 的 `OVERRIDES`,如第4课 挑=tiǎo、第6课 曲=qǔ)。`conf:"mid"` 的 8 课为待人工校对内容,UI 有黄点提示——这是留给教师的待办,新词库内容一律标 mid 直到确认。
- **听写**:Web Speech API(`speechSynthesis`),逐词朗读(语速/间隔/遍数可调),报完自动推进;错词随手记入错词本。
- **打印**:三个打印模板(生字表/看拼音写词语/听写纸),`#printSheet` 容器 + `@media print` 隐藏应用主体;打印前先 `fillSheet(html)` 再 `window.print()`。
- **快捷方式安装页**(设置页内):下载 `.url`(拖桌面即用)、`.bat`(写桌面+开始菜单,cmd `chcp 65001` 方案)、Mac `.webloc`。URL 取自 `location.href`。
- **血泪 bug(已修,别再犯)**:
  - CSS `display`(如 `.zgrid{display:grid}`)会覆盖 HTML `hidden` 属性 → 已加全局 `[hidden]{display:none!important}`;
  - 课文切换必须全局同步 → 已统一 `onLessonChange()`(重置报词台 dReset + 重渲染三个视图),不要再引入各视图独立的切换回调。
