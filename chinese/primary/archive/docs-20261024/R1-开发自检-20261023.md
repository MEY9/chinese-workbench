# R1 开发自检记录（2026-10-23）

> 状态：**开发完成的可测试原型，非正式交付**。当前主入口是 `../../app/index.html`；旧 P0 留档为 `index.v0.html`。已有 12 册 PDF 入包，仍须完成 G2 逐本内容校对；其他出版社文件待后续接入。

## 已实现

- 六个一级入口：今日、教学、批改、资料与打印、班级、设置；听写从教学进入。
- IndexedDB 业务数据，首次启动迁移旧版班级、配置、词库修改、当前课次与未归班错词；旧词可由教师逐条选择归班或留在个人词单。IndexedDB 不可用时明确提示并使用本机备用存储。
- 一至六年级、多出版社/上下册/版次目录元数据；班级绑定教材；`textbooks/` 离线 PDF 清单与文件 SHA-256 校验。当前已入包人教社统编版 **12 册 PDF**，其他出版社缺文件时显示“待导入”；所有已入包教材内容仍待人工核对。
- CSV 名册导入预览与冲突跳过；班级、教材版本、按学期起始日期汇总的周计划、课次进度、备课、听写、作业批改与讲评/复查关联。新增作业和复查采用页内表单，已保存听写可重新打开报词和打印。
- 首页数字由保存的记录计算；无记录显示空状态。听写支持词序调整、保存任务、中文系统语音、暂停/手动切词/自动推进；无语音时提示手动模式。
- 同页多表单的未保存内容在保存另一张表单后仍保留；取消离页不清草稿。重编号课次时，同教材下的备课、听写和作业记录同步调整。界面标明教材实际入包范围和未校对状态。
- A4 生字表、拼音练习、空听写纸、备课摘要、作业批改记录及共性错词复练单。学生版只输出拼音与作答线；教师答案独立打印。
- 版本化 JSON 备份、导入结构与对象数预览；默认排除 API Key。无外链脚本、字体、图片或 `fetch()` 启动请求。
- F12 快捷录入：50 人批改同表录入，讲评/复查可从名册批量勾选跟进学生，常用错例和措施模板可编辑；手动待办与讲评/复查最近一次状态切换可撤销。真实浏览器键盘验收仍未完成。
- 手动待办可修改和确认删除；讲评/复查可修正事项、日期、学生和结果。关键写入、状态切换、来源关联与打印再次核对当前班级和教材，避免仅靠界面过滤实现班级隔离。详见 [变更与发布审查](R1-变更与发布审查-20261023.md)。
- 写入失败回滚业务状态并保留表单草稿，处理中阻止重复提交；成功写入后的显示异常单独提示。读取失败、数据损坏、主/备用冲突进入恢复页，可导出副本和选择备份恢复；恢复成功清除旧任务上下文。实际浏览器持久性验收仍待完成。
- CSV 预览绑定目标班级，切班后清空并在确认导入时复核；已有批改的听写禁止替换词语集合，重排仍保留词频；批改人数和错人数输入非法时明确拒绝，保留草稿。切课停止报词并清理旧任务，复查来源在保存时复核班级与教材。已通过模拟回归。
