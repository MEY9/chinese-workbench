# SQLite 运行与迁移说明

更新：2026-10-23。依据用户明确要求，SQLite 是本项目唯一业务持久化数据库。原 PRD 中 IndexedDB、localStorage 备用和双击 HTML 直接编辑的规定已被本次决定替代。

## 运行

1. 本机安装 Python 3.10 或更新版本。本开发机使用 Python 3.12；无需安装第三方 Python 包。
2. 双击 `../app/start.cmd`，启动本机服务并打开工作台。已运行时复用服务。
3. 使用 <http://127.0.0.1:8765/>。断开互联网仍可工作，本机服务必须保持运行。
4. 数据库固定为 `../app/data/workbench.sqlite3`，与浏览器存储无关。教材仍在 `../app/textbooks/`。

开发时可运行 `python app/server.py`（前台服务，Ctrl+C 停止），或 `powershell -NoProfile -ExecutionPolicy Bypass -File app/start.ps1 -NoBrowser`（后台）。端口冲突时不会终止其他程序。后台进程号、标准输出和错误日志位于 `app/data/`。更换端口可传 `-Port`，迁移页的快捷链接默认仍指向 8765。

## 旧记录迁移

旧 `file://` 浏览器存储与 `http://127.0.0.1:8765` 是不同来源，服务不能直接读取原浏览器记录。因此此次完成了迁移能力，未宣称已迁入用户真实数据。

1. 使用原浏览器、原配置、原文件路径打开 `app/index.html`。现在文件页面只提供旧记录导出，禁止继续修改业务数据。
2. 导出主存储副本；若同时存在备用副本，也分别导出并核对。不会自动挑选一份覆盖另一份，不会删除原浏览器数据。旧 P0 数据也可转换成备份导出。
3. 在本机服务的设置页选择 JSON 备份，核对预览中的班级、学生、记录数量，再确认覆盖导入。已有 SQLite 数据时，先导出当前 JSON 备份。
4. 刷新并检查班级名册、备课、听写、作业与复查记录。重启服务再核对。有效备份默认排除 API Key；需要时在服务中重新填写。

故障副本不是可直接导入的有效备份。请保留原件修复，禁止用空数据覆盖。旧存储只有设置或词库时也应导出。

## 保存与备份行为

- 业务集合分表保存：classes、students、progress、preps、dictations、assignments、followups、tasks、customBooks、legacyWrong。每条记录以 ID、顺序、JSON 字段保存；有班级归属的集合设置 SQLite 外键。根配置与修订号在 metadata。
- 当前仍是单教师本地应用，每次提交整份状态，在同一 SQLite 事务中更新各表。不是多人协作服务，也未做增量实体 API。
- 启用 WAL、foreign_keys、synchronous=FULL；事务失败回滚。版本冲突返回 409，阻止旧窗口覆盖新记录。
- 请求标识支持重复请求去重；连接丢失会以同一标识重试一次。结果仍不确定时暂停保存，要求重新读取核对，不能宣称未写入。
- 前端失败时保留表单草稿；“重新读取数据库”会提示放弃未保存内容，请先复制需要保留的输入。草稿未持久化，不在 JSON 备份中。
- history 保留最近 20 次被替换的状态，供开发者恢复；当前没有历史恢复界面。这不替代教师主动导出的独立备份。
- 优先使用设置页的 JSON 导出。复制数据库文件时先关闭服务，并连同可能存在的 `-wal`、`-shm` 文件一起保留；不要在运行时仅复制主文件。
- API Key 若填写会存在本机 SQLite 中；数据库未加密。请按学生记录的访问要求管理电脑及备份文件。

## 接口与范围

服务只监听 127.0.0.1，检查 Host、Origin、跨站请求标识；状态接口使用本机会话令牌，不开放跨域访问。静态文件仅允许入口 HTML 和教材 PDF，数据库与源码不能通过 HTTP 下载。PDF 支持 Range 请求。

## 验收门禁

已建立自动测试：

- `node app/test_r1_data.cjs`：模拟 DOM 中的业务交互、保存失败及班级隔离。
- `node app/test_r1_storage.cjs`：SQLite 客户端加载、会话更新、请求去重、冲突和不确定结果处理；旧文件只读迁移。
- `python app/test_sqlite_server.py`：真实临时 SQLite 与 HTTP，覆盖落盘重读、100 人既有验收备份、表和外键完整性、事务失败回滚、历史记录、冲突、来源限制和 PDF 范围响应。
- `python app/test_textbook_pipeline.py` 与 `python app/build.py`：教材构建检查。

以上不等于正式交付。真实浏览器旧记录导出再导入、教师完整工作流、打印与教材内容校对仍需按 G2–G5 收集证据。SQLite 实现不解除既有发布门禁。
