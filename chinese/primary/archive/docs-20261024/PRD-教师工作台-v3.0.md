## 1. 背景:我们要解决什么问题

两轮小红书调研(168 帖 + 60 帖)反复指向同一个事实:**小学语文老师的时间被三类事情吃掉——课堂内的组织、课后的批改统计、以及大量重复制作纸质材料**。市面上的工具是一个个孤岛(点名软件、字帖生成器、成绩表格各一个),老师要在多个工具/小程序/Excel 之间搬运数据。

**本产品 = 把这些孤岛合成一个以班级名册为中心的桌面工作台**:名册建一次,点名、听写、打印、批改、跟踪全部复用;**AI 贯穿每个工作流**——它不是附加层,而是以学生档案(做过的题、听写、错题、批改、成绩)为燃料的常驻加速器。

### 用户画像(实证)
- **林老师,24 岁,新手语文老师兼班主任**:第一年带班,怕课堂失控、不会出练习、表格做得慢。需要:拿来即用的模板、一键点名、现成打印单。
- **王老师,35 岁,骨干语文老师**:重教学质量,批改认真但耗时。需要:评语库、旁批范例、错例跟踪、成绩趋势。
- **陈老师,45 岁,老班主任**:带班多年,管的是琐碎:座位、值日、收作业、成绩登记。需要:表格包、快速登记。

### 非目标(明确不做)
学生端/家长端、在线作业、自动给学生打分、云同步、排课系统、通用办公套件替代品。

## 2. 产品定位与成功指标

**一句话**:围绕"识字 → 听写 → 背诵 → 作业 → 作文 → 评价"教学闭环的、以班级名册为中心的小学语文教师本机工作台。

**成功指标(G5 教师试用验收)**
1. 新教师 30 分钟内独立完成首次闭环:建班 → 排课 → 打印一份看拼音写词语 → 课堂听写 → 批改登记 → 生成复练单
2. 单次听写的批改登记 ≤ 5 分钟(50 人班)
3. 任一打印材料 ≤ 3 步、1 分钟内出纸
4. 连续 5 个工作日试用,次日留存 ≥ 80%;所有首页数字可点回来源记录

---

## 3. 核心用户旅程(五幕)

```
第一幕 备课   建班建册 → 排课次 → 从教材词库/自建词库准备词单 → 打印练习与听写纸
第二幕 课堂   随机点名/抽背 → 听写报词(自动推进) → 背诵训练(挖空督背)
第三幕 批改   听写批改登记(全班错频/按学生) → 作业批改记录 → 作文旁批总评(评语库)
第四幕 跟踪   错例汇总 → 生成复练单/讲评 → 成绩登记与分析
第五幕 再教学 首页今日待办(来自真实记录) → 复查完成 → 循环
```

## 4. 信息架构(一级导航)

**今日 / 教学 / 课堂 / 批改 / 打印中心 / 数据与设置**

- 今日:真实待办首页(来自计划、批改、复查记录,空状态明示)
- 教学:班级名册、教材绑定、学期/周计划、课次、备课记录、词库校对
- 课堂:**随机点名与抽背、听写报词台、背诵训练**(三合一课堂模式,大按钮、大字号)
- 批改:听写批改、作业批改、作文批改(评语库/旁批)、讲评与复查
- 打印中心:全部纸型统一入口(生字词/听写/字帖/试卷/表格),左侧选项右侧实时预览
- 数据与设置:备份恢复、教材 PDF 管理、AI 配置、版本信息

## 5. 功能需求

### 模块 A:教学基础

**F1 班级与学生名册 — P0**
- 故事:作为老师,我建一次班级和名册,之后点名/听写/成绩都复用它。
- AC:①建班(名称/年级/册别/学期起始日);②手动逐个添加学生或 UTF-8 CSV 导入(学号/姓名,支持匿名代号),导入前预览冲突,取消不改数据;③同班学号唯一;④删除班级/学生有确认与备份提醒;⑤50 人名册增删改不卡顿。
- 证据:成绩登记表 1613 赞、作业登记 2811 赞(登记场景高频)。

**F2 教材与课次 — P0**
- 故事:作为老师,我把班级绑定到统编版某册教材,按课次组织教学与材料。
- AC:①教材目录(年级/册别/版本/文件/哈希)可管理,PDF 本机离线打开;②班级↔教材绑定,切班全量切换;③课次表:计划日期/实际日期/状态(未开始·已上课·已讲评)/备注;④**课次页码目录录入**(第 N 课起止页),作为后续"按课出题/朗读"的定位基础;⑤未校对内容明确标注"样例/待核",不冒充已核教材。
- 证据:教材 PDF 12 册已就位(用户 2026-10-23 提供);课次页码目录为 G2 剩余工作。

**F3 词库与词单 — P0**
- 故事:作为老师,我按课准备"写字表/词语表/自选词",听写和打印都从这里出。
- AC:①内置样例词库(标注待核)+ 教师逐课校对保存;②每课词单 = 写字表 + 词语表 + 自选词;③JSON 导入/导出;④词单被听写/打印引用时显示来源课次。

### 模块 C:课堂(P0,调研最大缺口)

**F10 随机点名与抽背 — P0(新增,调研最强新信号)**
- 故事:作为老师,我在课堂上随机点学生回答/上台抽背,公平且省心。
- AC:①从当前班名册随机抽取,大字全屏展示姓名;②模式:纯随机/顺延(23号→下一个)/排除已点(本轮不重复);③抽背模式:随机抽人 + 随机抽课文段落/词语;④历史记录本节课已点名单;⑤键盘空格=抽取,适配投影大屏;⑥离线可用。
- 证据:点名帖 20366/22624/11774 赞;"摇人抽背PPT"6336;"用随机点名软件"8922;"DeepSeek 随机点名"3774;"班主任随机刷新点"10220。**共 13 帖,现有产品零覆盖。**

**F11 课堂听写 — P0**
- 故事:作为老师,我课前选好词单,课堂上一键报词,自动推进。
- AC:①词单来自 F3,可勾选/排序/临时加词;②TTS 报词(语速/每词遍数/间隔可调),自动推进,暂停不偷跑,切页即停;③无系统中文语音时明确提示+手动模式;④投影模式:大字显示"第 N 个",可选显示词语对照;⑤批改入口在结束后直达。
- 证据:听写刚需(一轮调研);"严抓听默写真的有效"。

**F12 背诵训练 — P1(新增,语文特有)**
- 故事:作为老师/学生,我用挖空和提示帮学生背课文。
- AC:①录入或粘贴课文,自动按标点/关键词生成挖空(挖空密度可调);②TTS 朗读全文/当前句;③督背模式:卡住时提示首字/下一词;④记录每次背诵通过的课次。
- 证据:"背书匠"APP 14238 赞(AI 挖空/督背/耳返/音色)。

### 模块 I:AI 全线赋能(v3 核心模块)

### 模块 H:学生档案与 AI 建议(v2.1 增补)

**F29 学生档案(一生一档)— P0(v3 升级:它是全线 AI 的数据地基)**
- 故事:作为老师,我随手记录每个学生的情况,期末时每个学生都有一份完整档案,还能按学校要求打印记录表。
- AC:
  ①观察记录:`Record`(学生/类型/日期/内容/跟进状态),类型八种:闪光点、需关注、课堂表现、谈心谈话、家访、帮扶、家校联系、其他;随手记 ≤30 秒一条;
  ②学生档案页:基本情况 + **学业概览(自动聚合:听写错词史/作业错例/作文成绩与评语/成绩趋势/背诵记录,零额外录入)** + 记录时间线 + 历史评语;
  ③制度表单还原:按记录类型筛选,套学校格式打印(谈心谈话/家访/帮扶/个案辅导/家校联系);
  ④数据仅存本机;心理健康类个案标记后**不进入任何 AI 请求**;
  ⑤导出:单个学生档案打包(JSON+打印件)。
- 证据:一生一档/谈心谈话/家访/帮扶/个案辅导 5 帖 ≈8.4 万赞;老教师留痕方法论 14052 赞。

**F30 AI 实时建议 — F30a P1 / F30b P2**
- 故事:作为老师,我希望 AI 基于这个学生的真实记录,随时给我可用的建议和草稿,而不是让我空想。
- AC:
  ①**F30a 期末评语工作台(P1)**:逐生工作流——数据摘要(自动)→ AI 草稿 → 教师编辑 → 定稿;全班批量推进(n/N 进度);草稿基于该生真实记录生成、互不雷同;支持分层(优/中/待加强);一键排版打印到报告手册格式;AI 草稿带标记,定稿归档;
  ②**F30b 场景内联建议(P2)**:听写批改登记时(该生错词规律与专项建议)、作文批改时(结合历次评语指出进步/连续问题)、档案页(学期小结/辅导建议/家长沟通稿);
  ③隐私护栏(P0,随 F29 落地):请求默认脱敏(以"该生/学号"代称,不发姓名);发送内容摘要触发前可见;心理健康类记录永不进入 AI;AI 输出仅为草稿,教师逐条审核后归档;无 Key 时全部隐藏;
  ④失败重试与"不用 AI 也可完成全部流程"(AI 只是加速器)。
- 证据:期末评语 8 帖 ≈28.6 万赞;"批量生成全班评语个个不一样,三分钟搞定"25241 赞;反方"手写有温度"93526 赞 → 草稿+手改誊抄工作流。
- 对标:班级优化大师(行为点评数据→AI 评语,云端)vs 通用 LLM(无数据积累)——本产品以**本机学业数据+轻量观察记录+可脱敏 AI**差异化。

**F31 隐私护栏 — P0(随 F29 同步落地)**
- AC:①AI 请求不含学生姓名(默认代称),请求前展示发送摘要;②标记为"敏感"的记录本地留存、不进 AI;③无自动风险评分、无学生标签画像;④学生数据仅存本机与教师自管备份。

### 模块 J:特色组件与教材标注

**F33 首页小组件 — P1**
- 故事:作为老师,我的首页有一块会动的公告栏和一个好看的时钟,让工作台有"我的教室"的感觉。
- AC:
  ①跑马灯组件:内容在设置中配置(多条文本轮播,如班级口号/今日提醒/喜庆标语),可开关、调速、选样式(彩带底/纯文字);
  ②时钟小组件:三种表盘风格(翻页钟/圆润数字钟/课堂倒计时钟),课堂倒计时钟可设定分钟数(上课环节计时);
  ③组件开关与顺序可在设置中调整;组件框架可扩展(后续加值日生、课程表等);
  ④全部本地渲染,零网络。
- 证据:用户直接指定(2026-10-24);同类班级工具普遍带时钟/公告组件。

**F34 教材标注与 AI 备课分析 — 划线 P1 / AI 分析 P2**
- 故事:作为老师,我备课时直接在教材 PDF 上划线写批注,然后让 AI 告诉我"我划的都是什么、这节课该怎么讲"。
- AC:
  ①墨迹标注:阅读子页内画笔(多色/粗细)/橡皮/撤销,划线与手写批注按 `bookId+页码` 保存,可多套(备课/上课两套图层);
  ②文本映射:PDF 有文字层时,划线自动映射到被标注的原文文本;扫描版(无文字层)走视觉模型识别;
  ③**A12 划线分析**:一键把划线内容交给 AI → 输出教学重点归纳、可提问点、板书建议(草稿);
  ④**A13 整课分析**:结合页码目录+本课划线+课次词库 → 备课建议与教案草稿(教学目标/环节/提问链);
  ⑤标注数据本地存储,导出 JSON;AI 发送遵循 F32 脱敏管线(教材为公开出版物,不含学生数据);
  ⑥无 AI 时标注功能完整可用(纯手绘层)。
- 技术要点:PDF 渲染 pdf.js + Canvas 墨迹层(矢量笔画存储);文本映射用 pdf.js getTextContent 坐标匹配;视觉分析走多模态模型(OpenAI 兼容 vision),文本分析走对话模型。
- 证据:用户直接指定;同类需求(在教材上备课标注)与"AI 备课"为调研中备课集群的自然延伸。

## 6. 数据模型(核心实体)

```
Class(班级)─┬─ Student(学生)
            ├─ Progress(课次进度)─── Prep(备课)
            ├─ Dictation(听写任务)─┬─ DictMarking(批改:错频/学生记录)
            ├─ Assignment(作业)───┴─ Issue(错例)
            ├─ Grade(成绩, P1)      ── FollowUp(讲评/复查)
            └─ Task(手动待办)
Book(教材)── Lesson(课次页码目录+词库, 全局共享, 带 verifiedBy/verifiedAt)
WordList(词单) / ReciteLog(背诵记录, P1)
Record(观察记录: studentId/type/date/note/followUp/sensitive)
ReportCard(期末评语: studentId/term/text/aiDraftUsed)
```
规则:所有业务记录带 classId;学生级记录带 studentId;稳定 ID + updatedAt + 数据版本号;删除需确认;切班绝不串数据。
