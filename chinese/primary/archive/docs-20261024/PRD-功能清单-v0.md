# 语文老师工作台 · 功能清单 v0(基于小红书调研)

> 定位:**完全本地化**的单 HTML 入口工作台。应用与数据全部在本机(IndexedDB + JSON 导出/导入);AI 能力通过设置页接入 DeepSeek 官方 API(用户自己的 key),未配置时自动降级为词库/模板模式。已实测 `file://` 打开的页面可浏览器直连 `api.deepseek.com`(CORS 放行 `Origin: null`),无需任何中间服务器。

## 调研依据(2026-10-22 采集,数据见 `research/xhs/`)

| 痛点/需求 | 证据(小红书帖子) |
|---|---|
| 作文批改太耗时 | "10 分钟批改完 60 篇作文"(批量上传、逐句精批、评语风格、双屏润色、学情分析);学校要求"一学期 8 篇大作文全批全改,三处旁批三行以上尾批" |

| 低段生字/识字打印需求巨大 | "一上生字表写字表识字表" 6.5k 赞 3.9k 藏;"识字表组词" 5.7k 赞 5.4k 藏;课课贴、可打印是关键词 |
| 备课找资源累 | 高赞工具帖核心是"电子教材、教参、教案、PPT、讲课视频"一站集中(国家中小学智慧平台被反复推荐) |
| 出题组卷费时 | "教师出卷神器" 3.7k 赞;"用 DeepSeek 出初中语文试卷";"四步出卷法" |

## 核心设计决策:按学段分层(是,必须区分)

调研明确显示需求随学段变化(作文工具本身也按"2–9 年级课本习作要求"分级)。统编版(部编版)教材为全国基准,按册组织内容。

| 模块 | 小学低段(1–2) | 小学中高段(3–6) | 初中(7–9) |
|---|---|---|---|
| 生字词 | ★ 拼音/笔顺/识字表/写字表 | ★ 词语表/形近字/多音字 | ○ 字词积累(文言实词虚词) |
| 听写默写 | ★ 字词听写 | ★ 词语+古诗文默写 | ★ 古诗文/名著默写 |
| 作文 | 看图写话 | ★ 习作批改与评语 | ★ 大作文+中考作文 |
| 阅读 | 课内填空 | ★ 阅读理解题型 | ★ 文言文/名著导读 |
| 出题组卷 | ★ 字词卷 | ★ 单元卷 | ★ 中考题型卷 |

★=核心功能 ○=辅助功能。工作台首屏让用户选学段+册别,工具栏和内容库随之切换。

## 功能清单

### P0(MVP 第一版)

0. **AI 设置(DeepSeek)**
   - 设置项三件:`API Key`(密码框,仅存本机 localStorage,明文存储并提示)、`Base URL`(默认 `https://api.deepseek.com`,可改)、`模型名称`(默认 `deepseek-flash`,下拉建议 `deepseek-flash` / `deepseek-v4-pro`,允许自由输入)
   - 「测试连接」按钮:发一条最小请求,返回成功/失败与耗时
   - 可选「查余额」:调 `/user/balance` 显示剩余额度
   - 接口为 OpenAI 兼容格式,因此同一设置页天然支持:DeepSeek 官方、任意中转站、以及本机 Ollama(`http://localhost:11434/v1`)——后两者仅需改 Base URL 和模型名
   - 隐私明示:开启 AI 功能后,作文文本/题目内容会发送到所配置的 API 端点;key 只在本机保存、只在请求头发给所填端点
   - 全局降级:未配置 key 时所有 AI 按钮隐藏或置灰,其余功能完全可用

1. **学段/册别切换** — 选学段+学期后,词库、题型、模板全部联动;班级管理(多班支持)。
2. **生字词工作台**(小学)
   - 内置统编版各册识字表/写字表/词语表(本地词库,含拼音、部首、笔画、结构)
   - 生字卡视图 + 组词/造句
   - A4 打印:生字表、课课贴、看拼音写词语
   - 自定义生字本(收易错字)
3. **听写/默写训练**
   - 浏览器语音朗读听写(系统 TTS,可调语速/间隔/循环)
   - 按课选词生成听写序列;古诗文按篇默写
   - 听写纸打印(含田字格/四线三格)
   - 错词本:批改后错词自动进复习队列
4. **全本地数据** — IndexedDB 存储;一键导出/导入 JSON 备份;无任何网络请求(除用户显式访问的外链)。
5. **快捷方式安装页**(入口 HTML 内置,见下文可行性结论)

### P1(第二批)

6. **作文工作台**
   - 学生名册 → 篇目 → 批改记录;习作进度追踪(如一学期 8 篇登记)
   - **AI 精批(DeepSeek)**:粘贴或导入习作文本 → 按该年级习作要求逐句批注(病句/亮点/优化建议)+ 生成总评草稿;支持选评语风格(鼓励型、循循善诱型等);AI 结果仅作草稿,教师可逐条改后归档
   - 无 AI 降级:批改符号速查、评语库(按问题类型/风格组织的总评+旁批模板,符合"三处旁批+三行尾批"格式)
   - 学情统计:分数、字数、常见问题维度汇总,家长会可用;可让 AI 生成一段全班学情分析文字
7. **出题组卷**
   - 题型模板:看拼音写词语、形近字、多音字、近反义词、按课文内容填空、句式变换、阅读理解、古诗文填空
   - 本地题库 + 自建题库,按课/单元抽题
   - **AI 出题(DeepSeek)**:按"年级+课文/知识点+题型+难度"生成题目草稿,进编辑器人工确认后入库
   - A4 排版打印 + 参考答案页
8. **成绩册** — 录入/粘贴导入;平均分、及格率、优秀率、分数段分布;雷达图(字词/阅读/作文/积累)。
9. **古诗文与积累库**(中高段/初中) — 日积月累、古诗文默写篇目、名言归类。

### P2(后续)

10. **AI 能力扩展**(依赖 P0 的 DeepSeek 设置)
    - 期末学生评语草稿(按学期记录自动生成,教师逐条改)
    - 教案/教学设计草稿(第一/二课时结构)
    - 作文升格示例:同题双屏对比(学生原文 vs AI 润色版),标注改动点
11. **班主任事务包** — 课程表与早/午自习值班、家校沟通记录、表格收集登记表、期末学生评语库(模板+润色)。
12. **备课助手(轻量)** — 教案模板(第一/二课时,手写教案友好排版打印)、教学进度表、官方资源链接收藏夹(仅存链接,如国家中小学智慧平台)。

## 快捷方式可行性结论(调研:Windows 基本可行,Mac 部分可行)

| 目标 | 方案 | 可行性 |
|---|---|---|
| Win 桌面快捷方式 | 网页提供下载 `.url` 文件(纯文本,拖到桌面即用) | ✅ 高 |
| Win 带图标真快捷方式 | 下载"安装.bat"(PowerShell 建 `.lnk` 到桌面+开始菜单),双击一次完成 | ✅ 高(SmartScreen 可能提示,可在 bat 内注释说明) |
| 纯点击、无下载直接落桌面 | 浏览器沙箱禁止写桌面 | ❌ 不可行(所有平台) |
| Mac 桌面/Dock 快捷方式 | 下载 `.webloc` 拖到桌面或 Dock 右侧 | ✅ 高 |
| Mac "安装应用" | 打包极简 `.app`(shell 脚本打开 HTML)zip 下载,解压后拖入 /Applications | ⚠️ 中:文件从浏览器下载会带 quarantine 属性,首次打开需右键→打开(或页面提示一条 `xattr` 命令);纯点击自动进 /Applications 不可行 |
| 增强形态(可选) | 附带极简本地服务器 + PWA manifest,Chrome/Edge"安装应用"获得开始菜单/Dock 图标 | ⚠️ 与纯 file:// 单文件形态冲突,作为可选下载包 |

实施顺序建议:Win `.url` + `.bat`、Mac `.webloc` + `.app.zip` 四个都做,安装页按平台自动高亮对应方案,并诚实标注 Mac 首次打开需要右键确认。
