## 配色

|---|---|---|

每张统计卡/每个导航项有**专属主题色**(CSS 变量 `--mc` / `--nc` 下传)。状态必须文字+颜色双表达。Focus 环珊瑚红。

## 标志组件(均已实现)

- **侧栏**:暖白底,彩虹渐变圆徽,菜单项专属彩色图标,当前项 = 该项专属色实心胶囊白字,底部彩色书本插画(内联 SVG)
- **统计卡**:彩色圆角图标贴片(--mc 13% 淡底 + 同色描边)+ 主题色大数字 + 来源小字,悬停抬起
- **今日待办**:五彩序号章(轮换五色)
- **教学进度时间线**:竖线渐隐 + 状态色圆点(默认芒果黄/已上课草绿/已讲评丁香紫,外圈同色光环)
- **批改步骤条**:第N课 → 听写任务 → 批改记录(当前,天空蓝+光点)→ 复查
- **共性错词田字格卡**:拼音天空蓝 + 楷体字 + 虚线十字格(`tzWord()` 生成,拼音 token 数与字数对齐时逐字标注)
- **状态胶囊**:已批=草绿 / 待批=珊瑚红 / 待复查=丁香紫(淡底+同色文字)
- **空状态**:彩色田字格稿纸+铅笔内联 SVG 插画
- **模态框**(`uiConfirm/uiInfo`):遮罩模糊+白卡+状态色圆形图标徽章(危险=珊瑚红感叹号)+居中按钮组;**环境回退**:测试沙箱/无 DOM 时自动退回原生 confirm/alert(测试零改动)
- **打印预览**(`printHTML` 重构):所有打印先弹「暖米绒面书桌 + 白色 A4 纸」预览层,确认后才进系统打印
- **大屏**:≥1700px zoom 1.12 / ≥2000px 1.25 / ≥2400px 1.4

## 纪律

- 布局/类名沿用 R1;渲染层改动只走 `patch_cheer.py` 记录的锚点
- 欢快不幼稚:高彩集中在行动点与状态,大面积仍是暖白+白卡;对比度达标
- 打印介质黑白灰,无纹理无阴影;`prefers-reduced-motion` 全关动效

## 架构与来源(2026-10-23 第二轮:控件全美化)

`src/style.css` 按十层架构组织,改样式前先读文件头注释:L1 令牌 → L2 Reset → L3 排版 → L4 布局 → L5 组件(按钮/表单/卡片/数据/空状态)→ L6 覆盖层 → L7 工具类 → L8 动效响应式 → L9 大屏缩放 → L10 打印。**颜色禁止裸写,一律引用 L1 令牌;新组件先进对应小节。**

- 表单控件方案(下拉自绘箭头、复选/单选 appearance:none 自绘白勾、focus ring)提取自 **Pico CSS**(github.com/picocss/pico,~13k stars,MIT),按五色主题改造;Reset 思路来自 **modern-normalize**(MIT)。均以源码级融入,保持单文件零依赖,来源已在 CSS 文件头注明。
- 下拉弹出列表为系统原生(键盘/无障碍可达),可控部分(闭合态、悬停、聚焦、按值着色)已全定制;状态下拉按值自动着色:`tintStatusSelects()`(已批/已上课=绿,未交=红,待复查/已讲评=紫)。
- 已美化覆盖:下拉框、复选框、单选框、输入框、文本域、折叠面板(details)、表格、选项卡、按钮全系、滚动条、模态框、打印预览、Toast、空状态、时间线、步骤条、田字格卡。
- 布局密度:侧栏导航贴顶紧凑(品牌正下方),底部书脚注;`.grid{align-items:start}` 防卡片空拉伸;内容区 max-width 1760px;大屏缩放 ≥1600→1.15 / ≥1900→1.3 / ≥2300→1.5。
- 教训记录:侧栏导航曾用 `space-evenly` 均布导致"整体下滑",已回退为贴顶——**导航永远贴顶,全高利用靠表面与底部锚点,不靠散布菜单项**。
