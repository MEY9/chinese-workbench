## 1. 产品定义

**目标用户**：中国小学语文任课教师，兼任班主任者可使用后续扩展。R1 教学闭环先用现有三年级上册样例验证；教材目录和数据键从一开始支持一年级至六年级、不同出版社、上下册及版本年份，不能把界面或记录固定在“三年级上册”。

**一句话定位**：在本机完成小学语文教学的“备课与进度 → 上课/听写/布置作业 → 批改记录 → 讲评与复查”的个人工作台。

**核心价值**：教师一次记录可以在今日待办、班级进度、错例复练和打印材料中复用；减少散落在纸表、文件和脑中的重复整理。

**产品边界**：教师操作的个人工具，不提供学生账号、在线交作业、学校级排课/审批、家长即时通信或自动上传。AI 是明确选择的辅助能力，不能决定教材内容是否正确，也不能替教师给出最终评价。

### 本轮为什么重定范围

[补充调研](../research/xhs/teacher_workbench_20261023/调研结论.md)查看了 14 篇详情和 44 张配图。真实纸表反复出现“班级/课次/作业内容/错例/处理措施/复查”关系；现有应用主要提供生字词、报词和打印，班级只是名称，错词是全局列表，首页待办并非真实记录。新版先补齐教师工作流，再扩展更多生成工具。

## 2. 使用场景与成功标准

| 场景 | 教师目标 | 工作台必须留下的结果 |
|---|---|---|
| 周初安排 | 知道每班本周要上到哪课、要批改什么 | 每班的计划课次、实际进度与待办 |
| 课前备课 | 从课次进入目标、重点、活动和可用材料 | 与班级/课次关联的备课记录和打印入口 |
| 听写课 | 准备词单、发听写纸、自动报词 | 可回看的听写任务、词单和批改状态 |
| 批改后 | 迅速记全班共性问题和个别需跟进学生 | 作业记录、错例、讲评措施、复查任务 |
| 下次课 | 知道哪些问题要再练或讲评 | 来自上次记录的真实待办和复练材料 |

**试用指标**（作为验收目标，非调研事实）：教师无需培训能完成上述 5 个场景；同一班的一次听写从选词到生成复练单可闭环；所有首页数量可追溯到具体记录；0 次跨班串数据和 0 次数据丢失。试用时记录每个场景的耗时和卡点，与教师原有方法比较，不预设“节省百分之几”。

## 3. 版本范围与先后顺序

### R1：教师日常闭环（本 PRD 的开发范围）

1. 班级、学生名册、册别与课次；现有数据迁移。
2. 真实今日待办、按班教学进度、轻量备课记录。
3. 听写任务与现有报词/打印的整合；作业批改记录；错例、讲评、复查。
4. A4 材料输出、本地备份恢复、隐私与离线保障。
5. 教材中心的多出版社/一至六年级目录、班级教材绑定与 PDF 接入位。实际 PDF 由用户在开发完成后提供，交付前不可伪称内置或覆盖完整。

### R2：小学语文深度工作流（R1 试用通过后另审）

- 习作篇目与年级要求、学生文章登记、可编辑旁批和尾评、篇目级共性问题与讲评。
- 题库与组卷，优先复用真实错例和教材校对过的词库。
- 可选 AI 草稿：仅在教师主动触发时处理作文或题目，结果可逐条改、可拒绝、可归档，发送内容和端点明确提示。
- 成绩分析仅基于教师录入的成绩，不伪造“班级速览”。

### R3：可选班主任扩展

- 家校沟通事实记录、班级事务待办、期末评语草稿。默认不显示敏感学生标签或画像，不做自动风险评分。

**明确不纳入 R1**：跨设备同步、OCR 批量识别作文、自动给学生打分、学生/家长端、云端资源库、未经校对的全学段教材包、复杂排课与行政审批。已有 AI 词库生成按钮不得把模型输出标成真实教材数据。

## 4. 信息架构与关键路径

一级导航建议：**今日 / 教学 / 批改 / 资料与打印 / 班级 / 设置**。听写是“教学”内的任务；错例和作文是“批改”内的结果，避免每个小工具占一个一级入口。

```text
选择班级和册别
  → 查看本班进度、安排课次、写备课要点
  → 从课次建立听写或作业任务并打印
  → 上课使用报词；课后登记完成与错例
  → 生成讲评/复练待办，完成后标记复查
  → 首页显示下一步，所有数字可点回来源
```

切换班级时，进度、学生、任务、批改、错例和统计一并切换；公共教材词库可共用，但所有教学记录必须按班隔离。

## 6. 数据与内容规则

### 6.1 核心对象

`Class`（班级）→ `Student`（学生）；`Book`/`Lesson`（册别/课次）是公共内容；`TeachingPlan`、`LessonProgress`、`Assignment`、`DictationSession`、`MarkingRecord`、`Issue`、`FollowUp`、`Task` 均含 `classId`。学生级记录含 `studentId`，班级共性记录可留空。每条业务记录有稳定 ID、创建/修改时间和数据版本。删除采用可恢复或明确确认，绝不因切班而修改别班数据。

现有 `wb_wrong` 没有班级来源。迁移时放入单独的“旧版未归班错词”，由教师选择归属或保留为个人词单；不得默认分配给当前班。现有 `wb_lesson` 是界面选项，不等于教学进度；不得自动生成“已上课”记录。

### 6.2 教材数据可信度

- 交付包只对**明确标注教材版本/册别且逐项人工核对**的内容宣称“内置教材词库”。每课记录校对人、日期、版本；多音字按词语语境核验。
- 现有 16 课样例和 `conf:mid` 内容在校对前只能标“样例/待核”，不得在任务创建时默认为已核教材；教师可自行录入或导入词单。
- 若声称覆盖“三年级上册”，必须核实该册完整范围及生字/词语内容；做不到时缩小交付声明，不用模型补齐。
- 导入词库后做结构、重复项和空拼音检查；不因教师点击“保存”自动把数据可信度设为“已人工校对”。

### 6.3 打印与无网络边界

依据用户 2026-10-23 的明确要求，应用通过 Python 标准库本机服务运行，SQLite 是唯一业务数据库，固定保存于 `app/data/workbench.sqlite3`。前端仍构建为单个 HTML，无 CDN；正式工作入口是 `http://127.0.0.1:8765/`，需要本机 Python 服务。`file://` 仅提供旧数据导出迁移。所有业务表事务更新，失败回滚，使用修订号拒绝旧窗口覆盖，重复请求去重；设置页提供 JSON 备份与恢复。详见 [SQLite运行与迁移说明](SQLite运行与迁移说明.md)。链接到外部资源只在教师点击时打开。未来内置 PDF 以与 HTML 同包的 `textbooks/` 目录和构建期目录清单交付，不把几十本教材塞进 HTML 或 JSON 业务备份；PDF 未到位时用明确缺文件状态。教师手动选择本地 PDF 可在当前会话预览，但浏览器权限失效后须重新选择；不能把临时路径显示为已永久内置。具体文件命名和元数据结构见 [教材接入规范](教材PDF接入规范-v1.md)。

## 7. 视觉与交互规范（用于下一道视觉审批）

用户新要求：**小学语文主题欢快、鲜艳；内容区克制、厚重、有层次；避开传统橙色和暖色；全界面最多四种颜色。** 这覆盖旧版“珊瑚红/芒果黄/暖白”等视觉决策。[新版六张视觉候选图](../design/concepts/teacher-workbench-v1/README.md)已获用户批准，实施约束见 [UI 设计语言 v1](UI-设计语言-v1.md)。

### 建议材质：冷调厚卡纸 + 半哑光珐琅书脊

把工作台理解成一册可翻的教学记录本：导航和模块入口像有厚度的彩色书脊，内容区像压纹厚卡纸。视觉重量来自**边缘厚度、遮挡关系、内外阴影与微弱纤维纹理**，不靠大面积暖色渐变或泛滥插画。纹理优先用 CSS 实现，保持单 HTML 和打印清晰。

**候选四色，计入背景、文字与功能色，不另加第五种色相**：深墨蓝 `#1C2745`、冷纸白 `#F2F5FA`、电光蓝 `#3157D4`、亮洋红 `#AF1D88`。这组配色以冷纸白文字配蓝/洋红、深墨蓝文字配冷纸白时，三组正文对比度分别约为 5.58:1、5.73:1、13.48:1；不得把深墨蓝文字直接放在蓝/洋红上。同色透明度/明度派生可用于层次；红黄绿语义状态改用文字、图标与形状表达，不能只靠颜色。最终色值由视觉稿和对比度验收确定。打印稿以黑白灰为纸张输出，不作为屏幕界面的第五种品牌色。

- 首页和一级入口可用明亮颜色、圆润轮廓与适量图形，保持“小学语文”的亲和感；真实任务数据和操作按钮优先于装饰。
- 内容区以深墨蓝/冷纸白为主，主操作才使用电光蓝/洋红；同一屏的高彩面积建议不超过约 20%，作为视觉评审标尺。
- 卡片最多三级：页面底层、厚卡容器、浮起的操作层。层级必须对应信息关系，避免纯装饰叠片；阴影、纹理不降低文字可读性。
- 系统字体、内联 SVG；正文、表格、时间和数字清晰可扫描。200% 缩放不丢操作；正文与背景对比度至少 4.5:1，图标/控件至少 3:1；状态同时有文字。
- 新视觉稿覆盖：①真实数据与空状态首页；②教学进度/备课；③听写及批改记录；④习作批改方向页（R2 示意）；⑤ A4 打印。评审包含正常、空数据、长文本和 50 人名册状态。

## 10. 现有版本迁移与交付判定

现有生字卡、词库编辑、报词、三种打印模板和 JSON 备份作为可复用基础。首先修复听写自动推进、空选词退回全选、班级数据不隔离等与 R1 冲突的问题；首页的假“今日任务”和“班级速览”改为真实记录驱动。现有 `INDEX.md` 的“P0 已交付”仅指旧版工具原型，不代表本 PRD 的 R1 已通过验收。

R1 完成后，教师能用一个班级、一节课、一次听写和一次作业，从安排到复查独立走完流程；数据可在本机可靠恢复，纸质输出可直接使用，用户与真实教师的门禁证据齐全，才可标记“教师工作台 R1 已交付”。
