# R1 人工浏览器验收步骤

> 使用 Windows 11 上最新稳定版 Edge 与 Chrome 分别执行。自动 Browser Use 拒绝本地 `file://` URL，此次不绕过该限制进行浏览器自动测试；请人工运行 `../../app/start.cmd` 并打开本机 HTTP 工作台，旧文件只用于迁移导出。请先备份真实数据；以下测试使用完全匿名的 [2 班×50 人验收数据](fixtures/R1-2班50人.json)。

## 核心路径

1. **新环境与离线**：启动 `start.cmd` 后断开互联网，打开 `http://127.0.0.1:8765/`，保留本机服务运行。空首页不得显示虚构任务和非零统计。打开开发者工具网络面板，刷新后没有第三方请求。设置页显示当前本机存储模式。
2. **导入压力样本**：设置 → 选择备份导入 → 选择 fixture JSON。预览应为 2 班、100 学生、2 听写、120 作业、2 复查；确认后切换两个班。每班名册恰为 50 人，批改与进度不串班；首页和批改列表可在 3 秒内操作。
3. **班级与教材**：新建一年级上册班级，登记一个不存在的出版社/版次目录项，绑定后看到“PDF 待导入”；在教材中心切换“全部年级 / 1–6 年级”筛选。切回四年级验收班级，不能出现三年级样例词库为已核内容。改回其他班后原记录仍在原教材下。拿到真实 PDF 后检查“已核课次目录”可跳至对应 PDF 页码，未校对的书必须显示待核。
4. **课次与备课**：在验收三（1）班选第 20 课，修改计划/实际日期与状态，保存后刷新保持；在四（2）班看同编号课次，其日期和状态不变。填写教学目标、重难点、活动、板书材料与反思，保存、离页、重开验证。编辑未保存直接离页应有提示。
5. **听写**：从教学进入听写，选至少两词、调整次序、保存任务。清空全部词后“开始”必须拒绝。恢复词单后启动，观察自动按遍数和间隔推进；暂停 10 秒不应继续；上一词、下一词可用，末词只结束一次。关闭/切课应停止语音。无系统中文语音时显示手动模式提示，仍可手动切词和打印。
6. **批改与复查**：新任务记录参与 50、已批 42、两词错人数；可选给 A01 号登记错词，保存再打开不重复。建立全班讲评和指定学号复查，首页数量与任务相符；完成复查前必须写处理结果。完成后首页待办消失，历史仍可查看。
7. **作业批改**：新增作业，记录全班情况、至少两个“标签|错例”和处理措施；保存再打开内容一致。建立讲评和复查；切班后无数据混入。
8. **打印**：分别预览生字表、看拼音写词语、听写学生纸、教师答案、错词复练单、备课摘要和批改记录。A4 无导航、裁切、重叠或意外空白页；学生纸不得出现对应汉字答案；纸上班级、课次/任务、日期正确。
9. **备份恢复**：只用假 API Key 值测试；默认导出的 JSON 不含该值，勾选后才包含。导入损坏 JSON、类型错误的配置/词库、跨班引用必须拒绝且当前数据不变；导入有效备份后两个班、100 人及任务数恢复。恢复前先打开一个听写任务及 CSV 预览，恢复成功后旧听写词单、旧任务 ID 与旧 CSV 预览必须清除。换浏览器访问同一本机服务，数据应相同；迁移电脑前导出。
10. **可用性**：用键盘完成导航、主要表单和批改录入；焦点可见。浏览器缩放至 200%，主要按钮、50 人表格和打印入口仍可操作。长标题、长错例和长作文方向文案不遮挡操作。
11. **SQLite 失败、冲突与迁移**：仅用隔离数据库和匿名数据演练。停止服务后保存应失败且保留表单，恢复服务并重新读取核对后可保存。两个窗口同时编辑，后提交的旧版本必须报冲突且不能覆盖；重复点击不重复新增。响应丢失时提示结果未确认，重新读取核对后再重试。旧 `file://` 页面仅导出副本，在 HTTP 设置页导入后刷新并重启服务，原班级和记录数一致。恢复取消不改变 SQLite；损坏数据不得被空状态覆盖。自动证据见 `app/test_r1_storage.cjs`、`app/test_sqlite_server.py`；仍需记录真实浏览器结果。
12. **跨步骤修正**：在甲班选择 CSV，看清预览中的目标班级，再切乙班，旧预览应消失；重新选择后只导入乙班。听写批改保存后重开报词，取消一个词再保存应明确拒绝；恢复词后重排可保存且原错频不变。输入小数人数或超过已批份数的错人数，保存必须拒绝并保留输入。报词时编辑设置应暂停；返回教学换课后不得继续编辑旧听写。新建班级和换教材后，原复查的新建表单不得保留旧来源。

任何失败项记录复现步骤；G3/G4 必需项全部通过前保持“可测试原型”。教材 PDF 到位后的页数、课次映射和词库校对另走 G2。
