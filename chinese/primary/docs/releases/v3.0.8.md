# 语文工作台 v3.0.8

面向小学语文教师的 Windows x64 桌面工作台。

## 本次更新

- 厚装书本视觉：硬纸、书脊、叠页层次与教材风插画；统一界面字体、字号和行距。
- 优化成绩录入、课堂工具、班级切换、背诵记录、学生档案、打印及设置页。
- 修复成绩空值与零分区分、草稿恢复、日期计算、班级数据隔离及导入校验。
- 加强 SQLite 保存失败恢复、冲突处理、备份与恢复；改进 API 密钥的本地保护。

## 安装与数据

下载本页的 `.exe` 安装包，适用于 Windows x64。升级前请在设置页导出数据备份。

此公开安装包不附带教材 PDF，可使用自己合法持有的 PDF。班级和学生记录保存在本机 SQLite；不会随安装包上传 GitHub。AI 属于可选联网功能，需自行配置服务。

字体优先使用已安装的 Noto Sans SC，未安装时回退到系统中文字体；安装包没有捆绑该字体。安装程序未配置代码签名，Windows 可能显示发布者未知。

## 验证范围

发布流水线运行 10 项自动检查，覆盖脚本语法、数据与存储、课堂和成绩等业务回归、SQLite 服务、教材构建、Electron SQLite 存储及安装包内容一致性。公开包额外检查不包含 PDF。下载后可用同页 `SHA256SUMS.txt` 核对安装包完整性。

自动检查不等同于教师实用验收。真实 Windows 安装升级、浏览器视觉、投屏、实体打印和真实 AI 服务联调仍需人工验收。
