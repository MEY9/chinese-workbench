# 正式发布约定

2026-10-26 用户明确要求：安装包必须包含教材 PDF，以后持续遵守。

- 默认交付带教材的完整 Windows x64 EXE，不得用无教材包代替正式发布。
- 当前教材为人教社统编版语文 1–6 年级上下册，共 12 册。以后以 textbooks-manifest.json 为准，如实列出出版社、年级和册别。
- 源码 Git 仍忽略 PDF；教材随完整 EXE 发布到 GitHub Release。
- 运行 python chinese/primary/desktop/package-release.py，缺失教材或哈希不匹配必须终止，不能降级为无教材包。
- 发布门禁为 10 项自动检查、安装包与源码一致性、全部教材文件及哈希校验。人工验收范围在版本说明中单独列明。
- 从 desktop/dist/release/ 选择当前版本的 Setup-x.y.z-full-with-textbooks.exe 和 SHA256SUMS.txt 上传，不能混入旧版 EXE。
- GitHub Actions 仅作为不含教材的源码构建检查，不自动创建 Release。正式 Release 必须上传完整教材包后再发布。
- .env、API 密钥、用户数据库、学生数据和本机回滚备份不得随源码或安装包发布。
