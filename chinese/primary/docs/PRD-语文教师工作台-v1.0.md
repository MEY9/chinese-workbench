## 1. 产品定义

### 1.1 一句话定位
围绕小学语文"识字 → 听写 → 背诵 → 作业 → 作文 → 评价"教学闭环的、**以班级名册与学生档案为数据地基、AI 贯穿每个工作流**的本机桌面工作台(Windows / macOS)。

### 1.2 要解决的问题
两轮小红书调研(累计 276 帖)指向三类时间黑洞:
1. **课堂内组织**:随机点名、抽背、听写报词——老师们在用孤立的 PPT/小程序凑合(点名帖 13 篇、最高 22624 赞);
2. **纸质材料制作**:看拼音写词语、生字卡、字帖、听写纸、试卷——市面工具孤岛化、要会员(看拼音写词语 13 帖、生字卡 14 帖命中);
3. **批改与评价**:听写/作业批改记录、期末评语(8 帖 ≈28.6 万赞,"以前花一天现在三分钟")、一生一档工作留痕(5 帖 ≈8.4 万赞,"看着都怕")。

### 1.3 用户画像
- **林老师 24 岁,新手语文老师兼班主任**:怕课堂失控、不会出练习、表格做得慢。需要拿来即用的模板与一键工具。
- **王老师 35 岁,骨干语文老师**:批改认真但耗时,重视教学依据。需要评语库、旁批范例、错例跟踪、成绩趋势。
- **陈老师 45 岁,老班主任**:管琐碎——座位、值日、收作业、成绩、家校沟通。需要表格包与快速登记。

### 1.4 差异化定位
| 竞品 | 机制 | 弱点 | 我们的回答 |
|---|---|---|---|
| 班级优化大师(希沃) | 日常行为点评数据 → AI 评语/档案 | 云端存储(学生数据出本机);偏行为评价 | **学业数据自动沉淀 + 本机 SQLite + AI 可脱敏** |
| 通用 LLM(Kimi/Gemini 等) | 手动贴信息+提示词 | 无数据积累 | **档案页自动聚合,零额外录入** |
| 字帖/点名等小工具 | 单点功能 | 数据不互通 | **一个名册贯通所有工作流** |

### 1.5 非目标(明确不做)
学生端/家长端;在线作业;自动给学生打分;云同步;排课系统;心理健康诊断或风险评分。

### 1.6 成功指标(G5 试用验收)
1. 新教师 30 分钟内独立完成首次闭环:建班 → 排课 → 打印看拼音写词语 → 课堂听写 → 批改登记 → 生成复练单;
2. 50 人班一次听写的批改登记 ≤ 5 分钟;
3. 任一打印材料 ≤ 3 步、1 分钟出纸;
4. 期末评语:50 人班从 AI 草稿到全审定 ≤ 2 小时(对照"以前一天");
5. 连续 5 个工作日试用次日留存 ≥ 80%;首页所有数字可点回来源记录。

## 2. 用户旅程(五幕)

```
第一幕 备课   建班建册 → 绑教材排课次 → 词库/词单 → 打印练习与听写纸 →(可选)教材划线 + AI 备课分析
第二幕 课堂   随机点名/抽背 → 听写报词(自动推进) → 背诵训练(挖空督背) → 倒计时时钟
第三幕 批改   听写批改登记 → 作业批改 → 作文旁批总评(评语库+AI 草稿)
第四幕 跟踪   错例汇总 → 复练单/讲评 → 成绩登记分析 → 学生档案(观察记录随手记)
第五幕 再教学 首页今日待办(真实记录) → AI 预警解读 → 复查完成 → 循环
```

## 4. 功能需求

优先级:**P0**=首个可用版本必需;**P1**=第二迭代;**P2**=候选。每条含用户故事与验收标准(AC)。证据指调研帖(赞/藏),完整索引见 §9。

### 模块 A:教学基础

**F1 班级与学生名册 — P0**
- 故事:建一次班级名册,点名/听写/成绩/档案全部复用。
- AC:①建班(名称/年级/册别/学期起始日);②学生:手动逐个或 UTF-8 CSV 导入(学号/姓名,支持匿名代号),导入前预览冲突,取消不改数据;③同班学号唯一;④删除班级/学生需确认+备份提醒;⑤50 人名册增删改不卡顿。

**F2 教材与课次 — P0**
- 故事:班级绑定统编版某册教材,按课次组织教学与材料,备课时直接在教材上划线。
- AC:①教材目录管理(年级/册别/版本/文件/SHA-256),PDF 随包离线打开;②班级↔教材绑定,切班全量切换;③课次表:计划日期/实际日期/状态(未开始·已上课·已讲评)/备注;④课次页码目录录入(第 N 课起止页);⑤未校对内容标注"样例/待核",不冒充已核教材;⑥12 册统编版 PDF 已入包(2026-10-24,哈希清单见 manifest)。

**F3 词库与词单 — P0**
- AC:①内置样例词库(标注待核)+教师逐课校对;②每课词单=写字表+词语表+自选词;③JSON 导入导出;④被听写/打印引用时显示来源课次。

### 模块 B:打印中心

**F4 打印中心统一入口 — P0**
- 故事:选纸型→配置→实时预览→一键打印,≤1 分钟。
- AC:①左侧选项右侧实时 A4 预览(Electron `printToPDF` 渲染);②纸型统一元信息行(班级/姓名/日期);③打印输出不含界面元素;④支持导出 PDF。

**F5 看拼音写词语 — P0**
- AC:①词来源:按课词单/自选/错词复练;②版式:拼音+横线 / 拼音+田字格 / 拼音+方格;③每行词数可调;④答案页开关。

**F6 生字卡 — P0**
- AC:①来源按课写字表;②每页字数 6/8/9/12;③裁切线开关、大字版;④每卡:拼音+田字格+组词位(可选)。

**F7 听写纸与听默写字帖 — P0**
- AC:①空白听写纸(30/50 格);②按课听默写字帖(词/拼音两种+默写格);③默写计划表(按日拆分词单)。

**F8 字帖描红 — P1**
- AC:①按课写字表;②每字描红+空白格,重复次数可调;③笔画参照位(数据允许时)。

**F9 通用表格包 — P2**
- 成绩登记表、背诵听写默写跟踪表、作业收缴登记、座位表、卫生值日表、班级积分制。
- 证据:712/2811/4855/3983/1853。

### 模块 C:课堂

**F10 随机点名与抽背 — P0**
- 故事:课堂随机点学生回答/上台抽背,公平省心。
- AC:①从当前班名册随机抽取,大字全屏展示;②模式:纯随机/顺延(23号→24号)/排除已点;③抽背模式:随机抽人+随机抽课文段落/词语;④本节课已点名单记录;⑤空格键=抽取,投影大屏适配;⑥完全离线。
- 证据:13 帖,20366/22624/11774/6336/3774 赞。**调研最强缺口信号。**

**F11 课堂听写 — P0**
- AC:①词单来自 F3,勾选/排序/临时加词;②TTS 报词(语速/遍数/间隔),自动推进,暂停不偷跑,切页即停;③无中文语音时提示+手动模式;④投影模式:大字"第 N 个",可选词语对照;⑤结束直达批改。

**F12 背诵训练 — P1**
- 故事:用挖空和提示帮学生背课文。
- AC:①录入/粘贴课文,按标点/关键词生成挖空(密度可调);②TTS 朗读全文/当前句;③督背:卡住提示首字/下一词;④背诵通过记录进学生档案。

### 模块 D:批改与记录

**F13 听写批改 — P0**
- AC:①参与/已批人数;②全班错频(词×人数);③按学生登记(已批/未交/待复查+错词);④错频一键生成复练单;⑤数据关联班级+课次。

**F14 作业批改 — P0**
- AC:①日期/内容/关联课次/状态/全班情况;②典型错例(标签:字词/句子/阅读/习作);③处理措施;④需跟进学生。

**F15 作文批改与评语库 — P1**
- AC:①习作篇目按教材单元组织;②学生作文登记与批改状态;③**评语库按 15 维度**(语言/构思/观察/主题/结构/人物描写/情感/情节/选材/书写/标点/修辞/写法/开头/结尾);④旁批+总评范例按单元习作组织;⑤AI 草稿(A5)。
- 证据:9269/12252/3889/2442/2421/2081;夸奖式 44282 赞。

**F16 错例与复练闭环 — P0**
- AC:①错例来自听写/作业;②一键生成复练单(F5/F7);③讲评/复查待办关联来源;④完成后历史可追溯。

### 模块 E:数据与跟踪

**F17 成绩册与分析 — P1**
- AC:①多次成绩登记;②平均分/及格率/优秀率/自动等级;③两次成绩对比条;④历次趋势;⑤AI 解读(A9)。
- 证据:2977/1739/553。

**F18 今日待办 — P0**
- AC:①仅来自真实记录(计划上课/待批改/待讲评/待复查/手动);②可点回来源;③空状态明示;④切班/切日重算。

### 模块 H:学生档案与评语

**F29 学生档案(一生一档)— P0(v3 升级:全线 AI 的数据地基)**
- 故事:随手记每个学生的情况,期末每生有完整档案,按学校要求打印记录表。
- AC:
  ①观察记录 `Record`:学生/类型/日期/内容/跟进状态;类型八种:**闪光点、需关注、课堂表现、谈心谈话、家访、帮扶、家校联系、其他**;随手记 ≤30 秒;
  ②档案页:基本情况+**学业概览(自动聚合:听写错词史/作业错例/作文与评语/成绩趋势/背诵记录,零额外录入)**+记录时间线+历史评语;
  ③制度表单还原:按类型筛选,套学校格式打印(谈心谈话/家访/帮扶/个案辅导/家校联系);
  ④"敏感"标记的记录仅本地,不进 AI(F31);
  ⑤单个学生档案导出(JSON+打印件)。
- 证据:一生一档/谈心/家访/帮扶/个案 5 帖 ≈8.4 万赞;老教师留痕方法论 14052 赞。

### 模块 I:AI 全线赋能

**F32 AI 基座 — P0**
- AC:①上下文引擎:按场景组装提示词(学生档案聚合+当前任务数据+场景模板);②脱敏管线:姓名→代称、敏感记录过滤、发送前摘要可见;③供应商:DeepSeek 默认,任意 OpenAI 兼容端点,本地 Ollama 可选;**Key 经系统钥匙串加密**(Electron safeStorage);④失败重试/超时/流式输出;⑤无 Key 时 AI 入口全部隐藏,其余功能完整可用。

**AI 功能矩阵**(均输出草稿,教师审核后归档):

| ID | 场景 | 能力 | 优先级 |
|---|---|---|---|
| A1 | 听写批改 | 错词规律分析(如"的得地"连错 3 次)→ 专项复练词单 | P1 |
| A2 | 打印中心 | 个性化练习纸:按学生弱项为每人生成不同练习 | P1 |
| A4 | 背诵训练 | 课文自动挖空(标点/关键词/密度可调) | P1 |
| A5 | 作文批改 | 旁批+总评草稿,结合历次评语指出进步与连续问题 | P1 |
| A7 | 期末评语 | 全班批量草稿,每人基于真实记录互不雷同,分层可调 | P1 |
| A3 | 课堂听写 | 按课次与历史生成听写词单建议 | P2 |
| A6 | 作业批改 | 错例自动归类(字词/句子/阅读/习作) | P2 |
| A8 | 学生档案 | 学期小结/辅导建议/家长沟通稿 | P2 |
| A9 | 成绩册 | 成绩分析文字+异常预警解读(下滑/波动) | P2 |
| A10 | 教学/备课 | 课次教案草稿、课堂活动建议 | P2 |
| A11 | 预警 | 规则触发(连续未交/大幅下滑)时的解读话术 | P2 |
| A12 | 教材标注 | 划线内容分析:教学重点/提问设计/板书建议 | P2 |
| A13 | 教材标注 | 整课分析:页码目录+划线+词库 → 备课建议与教案草稿 | P2 |

**边界(不变)**:AI 只出草稿,教师审核后归档;不自动打分;不决定教材对错;心理健康类记录永不进入 AI;无自动风险评分、无学生标签画像。

### 隐私与安全(F31) — P0,贯穿全部模块

| 红线 | 要求 |
|---|---|
| 数据不出本机 | 档案/记录仅存本机 SQLite 与教师自管备份;零遥测 |
| AI 脱敏 | 请求默认以"该生/学号"代称,不发送姓名;发送摘要触发前可见 |
| 敏感记录隔离 | 标记"敏感"的记录(含心理健康个案)仅本地,永不进入 AI 请求 |
| 无画像 | 不做自动风险评分、不给学生打标签;AI 输出仅草稿 |
| 未成年人合规 | 遵循《个人信息保护法》《未成年人网络保护条例》最小必要原则 |
| Key 安全 | AI Key 经 Electron safeStorage 加密,不进明文配置/日志 |

## 5. 数据模型(核心实体)

```
Class(班级)─┬─ Student(学生)─── Record(观察记录: type/date/note/followUp/sensitive)
            ├─ Progress(课次进度)─── Prep(备课)─── Annotation(教材标注: bookId/page/strokes/layer)
            ├─ Dictation(听写任务)─┬─ DictMarking(错频/学生记录)
            ├─ Assignment(作业)───┴─ Issue(错例)
            ├─ Grade(成绩)          ── FollowUp(讲评/复查)
            ├─ ReciteLog(背诵记录)  ── ReportCard(期末评语: term/text/aiDraftUsed)
            └─ Task(手动待办)
Book(教材)── Lesson(课次页码目录+词库, 全局共享, verifiedBy/verifiedAt)
Widget(小组件配置) / AISettings(供应商/Key 引用)
```
规则:所有业务记录带 classId;学生级记录带 studentId;稳定 ID+updatedAt+数据版本;删除需确认;切班绝不串数据;主键/外键与状态校验沿用已验证的 server.py 方案(TS 移植)。
