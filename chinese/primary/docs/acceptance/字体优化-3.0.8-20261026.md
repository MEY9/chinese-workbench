# 字体优化 · 3.0.8

- 界面统一采用本机已安装的 Noto Sans SC，明确绑定 Regular 400、Medium 500、Bold 700 的真实字重。移除屏幕标题混用宋体、楷体、过重字重和过大字距的问题。
- 标题、正文、按钮、说明分别调整字号和行距；数字使用 Segoe UI 等宽数字特性，便于看成绩、人数和计时。
- 课堂模式按钮改为主标题与说明上下分层，选中态说明保持可读对比度。
- 点名投屏中的姓名、说明也统一字体；字形教学、背诵正文与打印保留原有适用字体。
- 厚魔法书的材质、插画与配色继续保留。本轮仅修改字体及相关排版，不改业务逻辑。

## 字体与离线使用

使用 CSS `local()` 读取已安装字体，没有复制系统字体，也没有请求在线字体。已核对 Windows 字体的名称与 PostScript 名称。其他未安装 Noto Sans SC 的电脑会回退到思源黑体、苹方、微软雅黑等系统中文字体，因此不宣称跨电脑字形完全一致。
