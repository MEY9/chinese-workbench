## 5. UI 梳理

### 5.1 可以保留

- 四个基础色令牌：墨蓝 `#1C2745`、冷纸 `#F2F5FA`、电光蓝 `#3157D4`、洋红 `#AF1D88`。
- 墨蓝侧栏作为外壳，冷纸作为内容底；主要动作蓝色，危险动作需明确文字。
- 厚卡边缘、轻纹理、浅凹槽有助于建立用户要求的材质感。
- 表格、卡片、输入框已具备统一基础；存在焦点样式和减少动效设置的适配。

### 5.2 需要调整的层级

| 当前源码表现 | UI/UX 影响 | 建议 |
|---|---|---|
| 10 个一级导航并列；课内子页缺父级高亮或明确返回 | 日常任务入口分散，进入点名/评语/座位后位置感不足 | 先补所有子页父级高亮和返回，再考虑合并入口；不直接推翻熟悉的导航 |

## 6. UX：按老师一天的工作重新接流程

### A. 第一次使用

推荐顺序：建立班级 → 导入名册 → 绑定教材 → 查看本册内容状态 → 开始备课。

需补：每步能返回、取消；导入冲突能定位行；保存后保持当前上下文；不要同时要求老师理解 SQLite 路径、R1 等实现术语。

### B. 备课与教材

推荐顺序：选班级/教材/课次 → 对应页 → 标注 → 查看实际发送内容 → AI 草稿 → 教师编辑 → 保存备课。

当前断点：没有课次页码映射；标注绘制错误；AI 输入不含课文；词单没有按册隔离。先修这些，才可称“教材辅助备课”。

### C. 课堂点名和背诵

推荐顺序：进入课堂 → 明确本班和本节课 → 选工具 → 大屏 → 教师确认结果 → 回到课堂。

要求：投屏隐藏教师隐私与表单；点名一轮可重置；背诵先选学生和课文，结束不能依赖此前打开过哪个学生档案。背诵“通过”由老师确认，不仅由提示次数自动决定。

### D. 听写、批改与复练

推荐顺序：词单 → 保存任务 → 报词 → 打开本次批改 → 快速登记 → 查看汇总 → 复练/复查。

当前需要老师同时手录已批份数、共性错频、逐生错词。建议提供“只记全班情况”与“逐生批改”两种明确模式；逐生模式自动汇总，有人工覆盖时记录来源。选择错词应支持点选本次词单，降低反复输入顿号分隔文本的成本。

作业功能应明确称“作业与批改记录”。当前没有学生端，也没有自动把作业发给学生的通道。若提供班群文案，应是预览、复制、老师自行发送，不能显示成已送达学生。

### E. 成绩与学生档案

推荐顺序：命名考试、日期、满分 → 批量录入/粘贴 → 标记未录或缺考 → 校验 → 保存 → 同口径对比 → 进入学生档案。

需补：考试名/日期可编辑；录分键盘连续操作；统计标注样本人数；档案能查看完整历史、按类型筛选及编辑误录。当前只有“最近 10 条”时不应给用户“记录丢了”的感觉。

### F. AI 评语与家长沟通

推荐顺序：查看证据 → 预览脱敏摘要 → 生成草稿 → 编辑 → 审定 → 打印/复制/归档。

要求：生成、审定和归档是三个不同状态；记录被修改后提示已有草稿可能过时；失败保留已完成项并可重试；批量任务有进度和取消。普通帮助文字不要声称“全线脱敏已完成”而缺少输入预览。

### G. 打印

推荐顺序：纸型 → 班级/课次/词单 → 行列与答案选项 → A4 分页预览 → 打印或导出 PDF。

当前弹窗预览是可保留的基础，但不是 PRD 的完整打印中心。重点补纸型配置、真实分页、缺数据校验和答案页隔离。学生练习与教师答案必须有明显区分，打印前检查缺拼音和跨教材内容。

### H. 数据与设置

推荐顺序：看到保存状态与最近备份 → 导出 → 导入预览 → 明确覆盖范围 → 可恢复。

需要：加密密钥的“已配置/未配置”状态及清除入口；连接测试不应悄悄改变未保存设置；高级提示词收起且能实际保存；历史恢复入口连接已经实现的 Store 能力。

file 页面、HTTP 服务与桌面安装版的存储解释必须一致。当前 file 分支使用 Browser 存储，但 startApp 又拒绝非 SQLite，设置还固定显示 app/data 路径。正式交付应明确一个主入口，兼容入口清楚标出用途。

## 7. 信息架构建议

当前实际为 10 个一级入口；PRD 写 6 个，已有变更记录也补充过其他模块。应先更新一份唯一有效导航图，避免开发继续按不同版本补菜单。

可考虑的收敛方案（设计建议，尚未直接修改）：

| 一级入口 | 二级内容 |
|---|---|
| 今日 | 今日待办、教学进度、可关闭的小组件 |
| 教学 | 教材与课次、备课、词单、周计划 |
| 课堂 | 点名/抽背、听写、背诵、计时 |
| 批改 | 听写记录、作业记录、作文（完成后再展示）、讲评与复查 |
| 学生 | 名册、成绩、档案、期末评语 |
| 资料与打印 | 教材库、纸型、表格、座位/值日；新闻可放辅助工具 |
| 设置 | 班级基础设置、数据恢复、AI、显示与小组件 |

一级入口只是组织建议。当前最优先的是修正按钮和状态、补齐上下文，不应先花一轮把全部导航重做。
