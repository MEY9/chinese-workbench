# 书本材质与教材风插画 · 3.0.6

## 本次交付

用户要求：UI 有书本的质感，加入教材风插画，生图使用 .env 中的 OpenAI 兼容接口。

- 侧栏：深墨蓝布面封皮、细织纹、内框压线与书沟阴影。
- 页头：书页式章节标题、洋红书签、叠页边缘、教材风山川与校园插画。
- 内容卡片：轻纸纤维与纸页厚度，保持表格、姓名和控件的可读性。
- 空状态：书册、练习本与燕子插画，替代原先的简单图标。
- 色彩：沿用冷白、墨蓝、钴蓝、洋红四个基础颜色。正文与表单继续用清晰的界面字体，仅章节标题使用宋体风格。
- 窄屏：720px 以下隐藏页头装饰图；插画不接收点击、不进入键盘焦点、不作为需要朗读的内容。
- 打印：新增材质样式限定屏幕，不进入实际打印纸张。

## 生图来源与文件

使用工作区 `eyes/.env` 中的 `OPENAI_BASE_URL`、`OPENAI_API_KEY` 和 `GPT_IMAGE_MODEL_NAME`。实际模型标识为该接口配置的 `gpt-image-2.5`；该名称为服务提供方标识，不在此推断官方模型身份。

通过 imagegen 技能自带 CLI 的 generate-batch 调用，生成 2 张 1536×1024 高质量 PNG。未使用内置生图服务替代用户指定接口。只发送插画提示词，没有发送学生记录、教材 PDF 或业务数据；没有把密钥写入源码、构建页面或交付文件。

提示词全文：`design/book-edition/prompts.jsonl`。
