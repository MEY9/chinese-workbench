# 统一下拉选择器 · 3.0.9

## 范围与样式

源码审计发现 17 处 select 模板。页面和弹窗中的单选下拉框统一增强：硬纸底色、三层底边、冷色描边、清晰焦点、选中勾标和状态色。菜单跟随触发器定位，底部空间不足时向上展开，宽度限制在视口内。长文字在菜单中换行，触发器显示省略和完整 title。

## 交互与兼容

- 10 个及以上选项显示本地搜索；支持名称、学号、全角字符匹配和无结果提示。
- 上下方向键移动、Home/End 首尾、Enter/空格确认、Esc 取消、Tab 离开。中文输入法组合输入期间不抢键。
- 只有值发生改变时才向原 select 发送 input/change，兼容原表单 FormData、草稿、筛选和保存逻辑。
- 选项只通过 textContent 输出，防止把选项文本当成 HTML。
- 支持禁用项、禁用 fieldset、必填校验、表单重置、动态选项和页面重绘；重复初始化不会产生重复控件。
- 弹层使用 Popover 顶层，仍保留在原弹窗的 DOM 焦点范围中，避免滚动容器裁切。Esc 不会误关业务弹窗。
- 没有引入运行时第三方选择器或 CDN；jsdom 仅用于开发测试。保留原生 select 作为数据源和打印回退。
- 当前没有多选或列表式 select；未来出现 multiple/size>1 时保持原控件，不错误地降级为单选。

## 方案调研

参考 GitHub [Choices.js](https://github.com/Choices-js/Choices) 的可搜索选择器、键盘控制和选中反馈思路。本项目采用独立组件以直接兼容现有整页重绘、委托事件及弹窗焦点约束；没有复制或打包 Choices.js。
