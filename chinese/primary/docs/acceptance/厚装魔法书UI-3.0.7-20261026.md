# 厚装魔法书 UI · 3.0.7

用户方向：厚重的书本、硬纸，像一本厚厚的魔法书。延续冷白、墨蓝、钴蓝、洋红四个基础色。

## 界面改动

- 桌面宽度下，应用增加深蓝硬壳外框、右侧厚纸断面、底部封板与装订阴影。
- 导航变为加厚书脊，加入分节压痕、布纹、内框压线和有厚度的蓝色书签选中态。
- 页头强化硬板书页、纸层断面、书沟和织物书签；正文卡片具有厚硬纸板边缘。
- 设置页重排为左侧本册目录、右侧连续内页：课堂偏好、数据保管、AI 助手、高级提示词。修复原先独立 h3、错误闭合 section 与不均匀双列造成的结构问题。
- 左侧目录可定位并聚焦对应章节；目录切换不重新渲染表单，保留未保存输入。
- 首页取消为填充窗口而强拉卡片高度，强化统计卡与课堂寄语的纸板层次。
- 教学页调整课次目录与编辑区域比例；小窗口改为纵向排列。
- 手机宽度收起外框和插画，确保内容可滚动；各项素材不阻挡点击，不进入键盘焦点。
- 新样式仅用于屏幕，打印仍使用原有白纸规则。

## 设置交互修正

- 补回课堂计时分钟输入，限定 1–180 整数分钟；无效值不会覆盖原设置。
- 分区保存保留其他分区的未保存草稿。
- 测试连接改为只测试已保存配置；有未保存 AI 配置时先提示保存，不再暗中修改服务地址或保存密钥。
- 备份文件选择采用可键盘操作的按钮。
- 去掉“R1 可测试原型”及未经验证的模型优劣、价格比较文案。
