# UI / UX 优化交付 · 3.0.5

日期：2026-10-26。

## 设计方向

参照用户此前选择的视觉稿（generated_images/01a163ee-998f-7610-b7d2-a7e1a14065dd/exec-f4ba400f-d4a0-42da-917d-4999036e7e32.png），保留墨蓝封皮、冷压纸张、蓝色主要操作与少量洋红强调。

四个基础颜色继续为 #F2F5FA、#1C2745、#3157D4、#AF1D88；中间层由它们混色产生。减少全局噪点和多层重影，让主要卡片保留厚度、嵌套内容保持安静。没有增加外部字体、图片请求或运行依赖。

## 已完成

### 全局

- 统一标题、正文、次要文字、间距、圆角与交互高度。
- 导航使用统一蓝色选中态；收紧导航间距，保留独立滚动和书脊材质。
- 浏览器顶栏取消桌面窗口按钮预留的 150px 空白；桌面版继续预留窗口控制区域。
- 按钮区分主要、次要、文字和危险操作；减少多个强色按钮同时争夺注意力。
- 表格增加固定表头、键盘焦点行提示，统一边框和留白。
- 原生下拉框、表单、弹窗、空状态、学生卡和教材卡采用一致的视觉层级。
- 补充 1100px / 720px 布局；新视觉规则限定屏幕，不改动打印介质规则。
- 档案记录类型改用主题色，去除原先的橙色、绿色等额外强调色。

### 成绩页

- 列表展示测评日期、均分、及格率、已录人数、缺考与剩余人数。
- 测评卡片展示登记进度；删除降为次要操作，继续录入是主要操作。
- 统计规则收进可展开区域，并明确及格线对所有班级生效。
- 详情分成统计区、名册录入区、保存区；AI 解读移至表格之后。
- 长表独立滚动，学生列和表头固定；输入框带学生姓名的可访问标签。
- Enter 下一位、Shift + Enter 上一位，跳过禁用的缺考输入；中文输入法组合输入不触发跳转。
- 分数变更即时更新等级、对比值和待保存提示，统计在保存后更新。
- 缺考、未录入、真实 0 分、非法分数使用不同状态；无有效分数时显示破折号，不显示 null。
- 成绩编辑存入独立 UI 草稿，保存前不改正式成绩；重新渲染保留草稿，确认放弃时清除。
- AI 解读前要求保存；空白登记表从完整班级名册生成，未录分数的学生不会被遗漏。
