## UI 与 UX 调整

- 保留现有冷色材质体系，内容区减少嵌套阴影。
- 侧栏允许独立滚动；子页面对应一级导航保持选中。
- 恢复原生 select 的键盘和选择行为，避免自定义包装失效。
- 修复 PDF 阅读与标注区域布局；座位表使用明确的列网格。
- 弹窗、长内容、长表和窄视口补充溢出规则；打印表头与学生分页补充规则。
- 设置说明明确 SQLite 路径与独立入口；旧评语、历史恢复、AI 草稿与审定状态可辨认。

这些 UI 改动已完成源码和逻辑检查，但本轮未获得浏览器截图。浏览器 URL 访问被当前安全策略拒绝后，未使用其他浏览器、远程调试或间接渲染绕过限制。
