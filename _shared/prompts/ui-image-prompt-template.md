# UI 视觉稿文生图提示词模板(已实战验证:小学语文 3 张零乱码)

> 接口:`.env` 的 `OPENAI_BASE_URL` + `OPENAI_API_KEY`,模型 `GPT_IMAGE_MODEL_NAME`(当前 gpt-image-2.5),尺寸 `1536x1024`,quality `high`。
> 调用方式:JSON 请求体写临时文件再 `-d @file`(防中文转义坏);响应可能是 `b64_json` 或 `url`,url 必须立即下载。

## 提示词七段结构(每段都必写,顺序即下)

```text
① 定位一句   「一张高保真的桌面端网页 UI 设计效果图,〈页面名〉——〈产品全名·一句话〉」
② 风格基调   欢快/鲜艳/精美/专业 + 目标用户(如:用户是小学语文老师)
③ 视觉体系   底色(给精确色值)+ 点缀色系列 + 圆角/投影/图标风格 + 参考质感(Dribbble 精品级 UI 设计稿、矢量插画)
④ 布局逐区块 顶栏有什么 → 内容第一行什么卡、卡内具体内容 → 第二行…;左/右侧栏逐项列出
⑤ 精确文案   每个组件要显示的中文文字原样写进提示词(如「三(2)班 · 三年级上册 · 部编版」「已批作文 38/42」)
⑥ 学科母题   语文:田字格(外实内虚十字)、拼音条、作文格线、红波浪批改线、着重号、圆形印章「优」等
⑦ 负面约束   「所有界面文字均为简体中文、清晰锐利可读;不出现英文乱码、不出现水印、不出现照片素材,纯粹的网页 UI 设计稿」
```

## 学段风格变体(③ 段替换)

| 学段 | 底色与点缀 | 质感词 |
|---|---|---|
| 小学 | 暖白 #FFF9F0;珊瑚红/芒果黄/天空蓝/草绿/丁香紫 | 16px 大圆角、扁平插画图标、贴纸感、欢快而有序 |
| 初中 | 冷白 #F6F8FA;靛蓝/青/橙三色克制点缀 | 8px 圆角、细线图标、信息密度更高、利落 |
| 高中/通用 | 纸白 #FAFAF7;单主色 + 灰阶 | 小圆角、无插画、强调排版层级,沉稳 |

## 生成纪律

1. 一张图只画**一个页面**;多页状态拆多张,不塞进一张。
2. 文案必须真实可用(真课文、真班级名、真数字),拒绝 lorem 或「示例文字」。
3. 同一工作台的所有页面重复同一段②③,保证系列一致;仅④⑤按页变化。
4. 生成后逐张检查:中文乱码 / 布局错乱 / 图标语义错,不合格改提示词重出,不手动修图。
5. 提示词原文件随图存 `design/concepts/prompt-*.json`,可复现。
6. **请求体必须 ASCII 转义**:`json.dump(obj, open('req.json','w'), ensure_ascii=True)` 生成 `req-*.json` 再 `-d @req.json`——gptapi 中转站对含原文中文的 JSON 偶发 `1163: JSON decode error`(2026-10-23 实测,prompt-1 连挂两次,转义后一次通过)。
7. 材质类提示词要把"光怎么打"写具体:珐琅光泽、右缘受光、底部厚度边、叠页暗影、绒面台面内阴影——只写"有质感"出不来质感。
